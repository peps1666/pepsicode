## 分类

- `guides/`：当前用户指南。
- `architecture/`：内核设计和边界约定。
- `development/`：开发、诊断、评测、发布及改进计划。
- `archive/`：历史审查与报告，不作为当前使用说明。

验收证据存放于仓库 `reports/validation/`；性能脚本与结果存放于 `benchmarks/`。
