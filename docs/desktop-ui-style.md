# 桌面客户端控件约定

界面使用暖灰侧栏、白色内容区、深灰主操作。配置、对话与权限界面沿用同一套语义色，避免让系统原生控件或局部配色形成第二套风格。

- **选择控件**：使用 `src/components/Select.tsx`。服务商、模型、思考深度、鉴权和输入时机共用菜单；项目内不要另外添加原生 `<select>`。选项主文字与辅助说明分层显示，选中项用勾号标记，悬停使用暖灰背景。
- **操作按钮**：配置流程使用 `Button.tsx` 的 primary、secondary、ghost 三种层级。每个弹窗底部只放一个主操作；刷新和配置 Key 使用轻量操作。
- **尺寸**：输入框和选择器为 40px 高、9px 圆角；弹窗为 18px 圆角、24px 内容边距。紧凑输入区允许使用 Select 的 compact 样式。
- **颜色与阴影**：复用 `theme/codex.css` 的语义色及 `--pc-*` 控件变量；菜单、弹窗、边框和焦点状态不单独引入蓝色选中态。
- **交互**：菜单支持方向键、Home / End、输入定位、Enter、Escape、Tab 和点击外部关闭。Escape 先关闭菜单，再关闭外层弹窗；菜单在窗口底部向上展开，长列表滚动，长模型 ID 换行显示。
- **验证**：改动控件后运行 `npm test`、生产构建和 `npm run release:smoke`；实际检查常规窗口与较矮窗口，菜单不能被弹窗裁切或超出视口。

v2.0.3 将模型设置、三步服务商配置、鉴权、输入时机切换为共用控件，并统一权限弹窗、复选框和权限菜单的视觉变量。配置、保存和重启使用沿用真实 ZIP 验收。
