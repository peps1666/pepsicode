# 桌面权限确认

需要审批时，输入框上方会显示操作对象、命令或路径。点击「查看请求详情」可核对工作目录、授权范围和请求原因。

| 选项 | 生效范围 |
| --- | --- |
| 仅允许这一次 | 授权当前操作。计划审批显示「批准计划」 |
| 本任务允许此命令 | 仅对当前任务中满足相同目录、参数、源码版本等条件的命令复用 |
| 本轮允许此文件 / 本轮允许所有文件编辑 | 仅在当前轮次内允许相应编辑 |
| 始终允许 / 始终拒绝 | 保存规则，后续匹配的请求沿用该决定 |
| 拒绝 / 拒绝并提出修改意见 | 阻止当前操作。选择附带意见时，可告诉模型如何调整下一步 |

卡片只显示服务端为当前请求提供的选项，其他授权范围可在「更多选项」查看。提交失败后，卡片保留请求和错误信息，可重新提交。命令拒绝规则与工作区默认模式见[权限与安全](permissions.md)。
